# User documentation

[Português](../portuguese-br%20version/INDEX_PT_BR.md)

Start with a synthetic calibration to understand preparation, execution and outputs. Then choose the analysis family and check whether your experiment is compatible with its assumptions. Advanced jobs require explicit nested configurations; the five-file M1 constructor does not automatically configure every analysis.
