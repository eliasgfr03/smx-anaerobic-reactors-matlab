# Documentação de uso

[English](../english%20version/INDEX.md)

Comece pelo exemplo sintético de calibração para entender preparação, execução e resultados. Depois selecione a família de análise e confira sua compatibilidade com o experimento. Os jobs avançados exigem estruturas de configuração explícitas; os cinco arquivos de entrada de M1 não configuram todas as análises automaticamente.
